# 🤖 Multi-Agent AI Research & Task Automation System

An advanced Agentic AI system where multiple specialized agents collaborate to plan tasks, conduct research, analyze findings, summarize information, and generate structured reports.

---

## 🚀 Project Overview

Complex tasks often require multiple stages of reasoning and analysis.

Instead of relying on a single AI component, this project demonstrates a multi-agent architecture where specialized agents collaborate through an orchestrated workflow.

Each agent has a specific responsibility.

---

## 🧠 Multi-Agent Architecture

```text
User Query
    ↓
Task Planner Agent
    ↓
Research Agent
    ↓
Analysis Agent
    ↓
Summarization Agent
    ↓
Report Generation Agent
    ↓
Final Structured Report
```

---

## 🤖 AI Agents

### 🧩 Task Planner Agent

Breaks the user task into structured steps.

### 🔎 Research Agent

Identifies key research concepts and investigation areas.

### 📊 Analysis Agent

Analyzes research findings and identifies important insights.

### 📝 Summarization Agent

Combines findings into concise information.

### 📄 Report Generation Agent

Creates a structured final research report.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Multi-Agent-AI-Research-System.git
```

Move into the project directory:

```bash
cd Multi-Agent-AI-Research-System
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
