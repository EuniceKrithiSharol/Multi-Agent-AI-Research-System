# AI Agents

The system contains multiple specialized AI agents.

## 1. Task Planner Agent

Breaks the user request into a structured workflow.

## 2. Research Agent

Identifies important concepts and research areas.

## 3. Analysis Agent

Analyzes findings and identifies opportunities and challenges.

## 4. Summarization Agent

Combines important information into concise findings.

## 5. Report Generation Agent

Creates the final structured report.
